## Как создать цель в Яндекс.Метрике

1. Перейдите в [Яндекс.Метрику](https://metrika.yandex.ru/).
2. Выберите счётчик **109279162**.
3. В боковом меню: **Настройки** → **Цели** → **Добавить цель**.
4. Выберите тип **«JavaScript-событие»**.
5. В поле **«Идентификатор цели»** введите строку из таблицы (например, `click_cta`).
6. Название можно задать понятное, например **«Клик по CTA»**.
7. Сохраните.
8. Повторите для каждого идентификатора из таблицы.

> Важно: идентификатор в Метрике должен совпадать с тем, что передаёт `ym(109279162, 'reachGoal', '...')` в коде, включая регистр.

## Проверка после настройки

1. Откройте сайт в режиме инкогнито.
2. В консоли выполните:
   ```js
   ym(109279162, 'reachGoal', 'click_cta');
   ```
3. Через несколько минут в Метрике: **Отчёты** → **Конверсии** — цель должна засчитаться.
4. Можно также использовать расширение **Yandex.Metrica Debug** для Chrome.

---

## Также отправляется в Google Analytics 4

Каждый вызов `reachGoal` дублируется событием `gtag('event', 'идентификатор')`. Если в GA4 нужны отдельные события — они уже поступают, остаётся только пометить нужные как конверсии в интерфейсе GA4.
